How it works

  • Flashcards three ways. Word → definition, definition → word, and fill-in-the-blank sentences. When you're recalling the word, letter hints are there if you want them.

  • Five games that teach. Synonym match, definition match, sentence equivalence, Mood match and Word wash — each one built around a different way the GRE asks about a word.
  • Mnemonics. Memory hooks on more than a thousand words, plus room for your own.
